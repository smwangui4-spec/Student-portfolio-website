# Samuel Mwaura — Portfolio

A responsive, static portfolio website for a student learning cybersecurity and ethical hacking. It uses plain HTML, CSS, and JavaScript; no build step or package installation is needed.

## Included

- Responsive navigation with keyboard-friendly menu controls.
- Light/dark theme toggle and a floating back-to-top control.
- Cybersecurity focus areas and a learning roadmap covering foundations, safe practice, and clear reporting.
- A contact form that opens a pre-filled email draft in the visitor's email app; it does not store or send submissions automatically.
- Portfolio project and learning sections intended to be updated as real work and qualifications are completed.

## Preview locally

Open `index.html` in a browser.

## Personalize before publishing

- Add completed, authorized case studies to **Selected Work** as you build them; keep claims and results verifiable.
- Update the **Learning Roadmap** to reflect the topics you are actively studying.
- Update **Learning** with courses or certifications only after completing or earning them.
- Add a professional email address if you want visitors to contact you by email.
- Update the Instagram link in the contact section if your preferred contact channel changes.
- Replace `assets/cybersecurity-profile.svg` with a professional portrait if you prefer a personal photo.
- Update the page title and description in `index.html` if your preferred role wording changes.
- After publishing, set the Open Graph and Twitter image URLs in `index.html` to the full HTTPS URL for `assets/portfolio-preview.svg` so social platforms can fetch the preview image.

Do not publish client data, credentials, or details from security work that you are not authorized to disclose.

## Publish online

One simple option is GitHub Pages:

1. Create a GitHub repository and add `index.html`, `styles.css`, `script.js`, and the `assets/` folder.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. When deployment completes, GitHub Pages will show the public site URL in the Pages settings.

You can also upload the three site files to any static web host.
